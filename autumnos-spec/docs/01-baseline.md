# 01 · 需求基线与边界

**制作人：派蒙。基线版本：0.2（范围沿用0.1，补充真实Logto配置）。** 本文件描述要实现的目标，不表示已实现。

## 产品与交付

名称 Lab Chronicles AutumnOS；系统界面主标题可用 AutumnOS，副标题 Lab Chronicles，独立展示“制作人：派蒙”。Windows 原生客户端以 AutumnOS.exe 为入口，默认普通窗口，可最大化，提供全屏切换但不强制全屏。

兼容目标为 Windows 10 22H2 与 Windows 11 的 x64。必须记录实际测试过的系统构建号；运行兼容目标不等于为系统本身提供安全支持。

同时交付便携 ZIP 和安装 EXE。双击程序即可启动，不要求用户自行安装 .NET；发行工程分别处理 .NET、Windows App SDK 与 WebView2 Runtime。WinUI 3 自包含目录允许携带 DLL，不强求单一物理文件。[S1][S2][S3]

数据根为入口 AutumnOS.exe 同级的 AutumnOS_Data。目录涵盖 Apps、Packages、Downloads、Cache、AppData、Saves、Screenshots、Config、Logs、Runtime、Temp、Updates。安装程序默认采用当前用户可写位置；只读目录给出明确可恢复提示，不悄悄改存储位置，不要求日常管理员运行。数据根与代码升级文件清单分离。

## 桌面与使用体验

首启 hello → AutumnOS → 初始化 → 桌面；初始化支持取消与断点恢复。后续启动不重复首启配置；提供减少动态效果与跳过过渡的设置。原创视觉、流畅反馈和清晰层级比复制素材重要。

多页桌面、Dock、文件夹、应用资料、图标长按菜单、空白处长按编辑、拖动与重排、桌面搜索、应用库、通知中心、控制中心、多任务卡片属于规划范围。鼠标右键提供长按菜单的等价操作；拖动不能误触长按，关闭菜单、取消拖动、键盘返回与焦点恢复均需定义。

应用移出桌面、卸载应用、清除数据为不同操作。系统应用不可随意卸载；可允许从某页移走但仍能从应用库找到。长按快捷操作声明在清单中，只触发受限的应用事件。

个性化覆盖静态/动态壁纸、深浅色与自动模式、图标大小与外观、网格、Dock、透明度、模糊强度、动画、声音、布局备份、语言、缩放、减少动态效果和高对比易读模式。性能不足时允许降低特效，不得影响基本操作。

## 应用模型

万物皆软件：系统设置、商店、下载、账号、存档管理和开发者工具作为系统应用从桌面使用。第三方 .autumn 应用必须在主程序内部呈现。

工程验证采用 Web/WASM 内容 + WebView2；这是实现基线，需要通过输入、图形、尺寸变化、存档、生命周期和权限验证。不能承诺所有 Unity/Godot/其他引擎作品直接兼容；开发者须交付经过目标运行环境验证的构建。

一个可见应用不等于一个操作系统进程；运行管理器掌握真实的应用实例和游戏会话。回到桌面不表示游戏已退出。第三方应用不得提供任意原生可执行文件或宿主 DLL 扩展。

## Store 与下载

入口 Topic 为 `autumnos-app`；分类 Topic 必须保持 `autumn-app-pm` 与 `autumn-app-sq`。以用户指定的这三个字面值为准。

直接通过 GitHub 搜索发现，首版一仓库一应用。没有合规 Release 安装附件时不显示可安装。详情显示来源、版本、兼容性、空间、权限、说明、截图；支持版本选择、稳定/预览、来源、类别、离线能力、已安装状态和兼容性筛选。

应用固定版本、预览开关、降级前存档兼容检查、下载队列、暂停恢复、重试、并发和限速、缓存、安装队列、修复、备份与卸载需通过真实服务实现。仅服务端支持 Range 且资源标识不变时继续断点，其他情况安全重下。

本轮暂不建设任何由派蒙维护的认可名单或审核平台。pm/sq 为仓库自行声明的分类，不授予额外权限，不成为发布者身份或安全证明。两种分类同时存在时显示“分类冲突”，不自动优先算 pm。

GitHub 代理设置区分系统代理与 GitHub HTTP 下载地址加速。默认直连、可测试、可回退、可禁用；不能代理 Logto 登录或转发凭据到任意第三方。代理异常不绕过校验。

## 账号、权限与开发者

系统浏览器、OIDC 授权码和 PKCE；用户可以离线或游客使用不依赖账号的功能。第三方需声明、请求、接受拒绝和撤销，返回最小用户资料。切换账号必须隔离数据并废弃旧会话请求。[S7]

权限实际落实在宿主、资源访问与运行时，不只是弹窗。默认私有数据、无任意文件系统访问、无任意宿主命令；浏览器原生能力同样纳入威胁模型。[S4]

开发者模式在设置中开启，自动显示开发者应用；关闭后隐藏调试入口但保留正常用户数据。支持官方模板、SDK、日志、预览、打包、检查、账号与权限测试、生命周期模拟和发布检查。开发者可以使用自己的 AI，但模板和对接文档必须使人类开发者独立完成接入。

用户资料读取与开发者自己的服务端登录属于不同协议。服务端身份方案、云同步、成就等能力应有明确的服务边界和支持状态；没有实际后端不能宣传可用。
