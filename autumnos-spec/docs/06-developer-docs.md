# 06 · 文档、样例与开发工具交付

用户要求开发者能够独立完成对接。因此文档是产品的一部分，不能等所有功能做完后用想象填补接口。下面是最终文档站建设清单；本执行包只给出合同与目录，不冒充已经完成这些实现文档。

## 按版本交付的专题

| 文档组 | 必须完成的专题 |
|---|---|
| 产品 | 产品范围、术语、需求追踪、限制与已知问题 |
| 架构 | 总览、模块依赖、进程边界、数据流、ADR、威胁模型 |
| 核心开发 | Windows 环境、构建、运行、调试、线程/并发、配置、依赖版本 |
| 设计 | 视觉规范、首启、多任务、长按/拖动、易用性、键盘与触控、缩放 |
| 应用入门 | 第一个应用、模板、内部运行限制、生命周期、调试与打包 |
| 应用包 | .autumn 格式、manifest schema、资源校验、权限、版本兼容 |
| 用户与权限 | Logto 配置、用户资料授权、取消/拒绝/撤销、退出、切换账号 |
| SDK | 每个公开方法、事件、错误、限制、并发、取消、支持版本 |
| 数据 | 私有设置、文件句柄、存档、迁移、备份恢复、删除和用户归属 |
| 服务端 | 应用身份方案、HTTP API、凭证校验、开发环境、权限、部署 |
| 桌面扩展 | 快捷操作、通知、角标、深层链接、小组件、外观事件 |
| 网络 | 网络权限、重定向、离线、GitHub 代理与应用网络的区别 |
| 应用发布 | Topics、GitHub Releases、清单生成、版本筛选、来源变化 |
| 主程序发布 | plus/meta、构建双包、签名、更新器、恢复、密钥更换 |
| 运维与排错 | 脱敏日志、故障包、缓存、损坏修复、限流与连接错误 |
| 协作 | 贡献指南、分工、PR 模板、接口变更、测试、发布检查 |

每个专题落成独立可搜索页面，文档标注适用版本；不把“稍后补充”页面统计为完成。开发文档优先中文，API 标识保持一致。

## 每个接口页面的统一模板

目的、内部/公开/服务端边界、最小平台版本、调用者身份、所需权限、用户交互要求、输入字段与限制、成功/空/缓存输出、错误码、重试/幂等、取消/超时、并发、后台/退出行为、账号切换/撤销行为、数据归属与清除、示例、测试链接、版本与废弃说明。

正常示例和拒绝/失败示例都需要。对外服务端接口交付 OpenAPI；JSON 清单与消息交付 schema；SDK 交付类型定义。机器描述和文档必须由真实代码或合同测试保证一致。[S9]

## 必需样例

| 样例 | 验证目标 |
|---|---|
| hello-app | 模板→打包→安装→桌面→内部运行→退出 |
| identity-app | 真实登录资料授权、拒绝、取消、撤销、账号切换 |
| save-game | 知识配对小游戏、自动保存、恢复、格式升级与失败保护 |
| desktop-extension | 长按快捷操作、通知、主题变化、小组件 |
| backend-identity | 开发者服务器验证身份、错误 audience/过期凭据的拒绝 |

化学示例仅用于抽象知识学习，不包含危险实验的操作教程。

## 开发工具

统一 CLI 与开发者应用共享校验引擎，能力为创建、检查、预览、调试、打包、检查发布材料。命令名称在实现时冻结；文档中的命令必须能复制执行。

开发者模式可模拟权限拒绝、切换账号、离线、后台与退出；这些模拟必须清楚标记，退出开发者模式后不影响正式用户会话。调试器不显示令牌，不把调试权限传给所有第三方应用。

## 自动检查

构建全部样例、SDK 类型检查、schema 正反例、文档链接、HTTP 合同、公开符号变化、兼容性测试、秘密扫描、发布材料检查。测试摘要关联实际本地源文件快照/内容哈希；已有且获准使用的commit可附加。本地脚本可执行全部检查，不依赖云端CI。

新人验收：只阅读对应版本文档，从空目录完成一个新应用并接入资料授权和存档。任何依赖口头补充的步骤都回写文档，直到可以独立复现。
