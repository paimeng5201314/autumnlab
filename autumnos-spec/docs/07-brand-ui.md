# 07 · 品牌与 UI 验收基线

## 固定署名

完整产品名：Lab Chronicles AutumnOS。
系统显示名：AutumnOS。
制作人：派蒙。
入口：AutumnOS.exe。

品牌文本集中放在一个由产品元数据生成的配置中，避免不同模块写成其他名字。README、首启完成页、关于页、启动品牌页、安装程序和 Release 说明均包含“制作人：派蒙”。不替换第三方版权或实际证书主体。

## 首启与启动

采用原创 hello 手写/描绘式过渡、AutumnOS 品牌与桌面渐入。允许减少动态效果、跳过和中断恢复。品牌页以 AutumnOS 为主，Lab Chronicles 和制作人署名次级但清晰可读，不借用 Apple 商标、系统原始素材、音效或未授权字体文件。

普通启动轻量进入桌面；不重复显示第一次欢迎问答。应用内部返回桌面与关闭程序是不同动作。

## 桌面交互

长按应用：缩放反馈、清晰上下文菜单，点击空白/ESC 关闭；右键等价。拖动阈值与长按时长写成统一交互常量并实测，避免拖图标时不停弹菜单。

编辑模式：可重排、跨页、进出文件夹、进出 Dock；取消回到原位置。删除图标、卸载与清数据必须分开；系统关键应用不可无确认移除可达入口。

应用内部：默认占满主工作区，有统一返回桌面与多任务路径；窗口缩放保留状态。设置和商店同样作为系统应用打开，不能退化为始终占屏幕左边的普通启动器导航。

多任务：卡片显示实例真实状态；后台游戏仍算运行。关闭先询问保存/生命周期，失败不假装已结束。游戏画面、系统遮罩和权限弹窗的叠层要进行 Windows 实测。

## 个性化与控制

壁纸、深浅色、图标外观/尺寸、布局、Dock、透明度、模糊、动画、声音与易用性实时预览并可恢复默认。减少动态效果影响首启、桌面、应用转换和所有系统应用，不能只改一个页面。

控制中心只显示真实可读/可控能力。系统音量与应用音量明确区分；网络状态不可假装能切换不支持的系统网络设置。通知中心支持来源、时间、已读和静音。

## 视觉证据

需要首启、桌面、长按菜单、编辑状态、文件夹、商店列表/版本页、下载队列、账号授权、设置、游戏内覆盖层、多任务、更新等待、故障恢复、关于页的实机截图或录像。

截图只证明视觉，不替代按钮操作和数据验收。最终美观由派蒙审阅；工程人员不得凭自己的审美删改固定品牌或交互要求。
