## 欢迎与准备

单文件准备器仍使用 Windows 原生 .NET Framework 窗口，在 WinUI 运行负载可用前显示应用尺寸的米白、墨绿准备界面。校验资源、展开资源、核对文件都显示实际字节或文件进度；支持取消并保留未提交目录的安全边界。文件工作放在独立线程，界面使用正常消息循环读取真实进度，不再用 `DoEvents` 推进同步文件任务。取消先请求停止，待工作线程释放文件句柄后才关闭窗口；主线程始终持有提取互斥锁，直到工作线程退出。哈希、清单、路径验证、入口绑定和提交规则保持不变。它不是认证动画，也不宣称进行未实施的权限检查。业务客户端依然是 .NET 10 / WinUI 3，内部应用仍由 WebView2 承载。

这项响应修复来自一次真实失败：`refresh-04` 的单文件首启在哈希显示完成与首个输出文件之间出现约360秒空档，超出原90秒预算；随后确实完成并正常退出。原失败和后续收尾分别保留，不能把它改为成功。具体 Windows/UIA 调用栈未取得，因此未宣称已证实某一外部调用是根因；最终独立首启与线程/取消回归结果以最新交付证据为准。

欢迎流程为多语言问候、手写品牌、个性化、可选账号、桌面。六排问候交替横向滚动；第一步点击下一步后，hello 上移并缩小，原生折线依次描画本地原创的 autumnOS 签名。离开欢迎页即停止动画；遵循 Windows 减少动画设置。品牌动画不阻塞继续按钮。

欢迎容器有独立浅色主题，切换个性化卡片只选择并保存实际桌面主题。步骤之间不再对整个欢迎容器淡入，避免露出底层桌面主题造成闪色。卡片分别预览浅色、深色桌面，当前选择有边框和可访问提示。桌面使用真实已保存主题。

账号独立成页，支持登录并保持登录、取消、重试和跳过。首次账号决策沿用云端 `FirstRunAccountCoordinator` 与引导状态 v2；老版已完成引导不重复进入。登录凭据与引导决策分离，真实身份只有通过系统浏览器 OIDC/PKCE 校验后成立。回调端口保持 127.0.0.1:17853，不改线上注册，不索取 Client Secret。

首次和设置账号页共用有限中文错误映射；服务错误不回显授权码、令牌或任意远端错误正文。2026-10-17 本机公开 discovery 实际返回 HTTP 502，因此真实线上登录尚未通过；代码修复和本地协议夹具不代表线上服务恢复。现有配置和历史登记说明均保留。

## 游戏快捷键

- Esc：返回桌面，保留同一游戏会话和未保存输入。
- Ctrl+Shift+Q：请求结束当前游戏，仍需确认，取消保留游戏。
- F6：在桌面打开多任务，可以继续或结束已运行应用。

游戏顶部的返回和结束操作栏已移除，内容铺满内部视口。首次进入短暂显示键盘提示；权限或结束确认弹窗打开时，Esc 只作用于弹窗。快捷键使用窗口加速器及原生输入桥，不新增任意网页消息关闭通道。WinUI 的 WebView 输入焦点位于独立浏览器进程，普通 XAML 作用域无法可靠接收按键；原生桥只在游戏页可见时启用，先核对前台为本窗口或当前 WebView API 返回且持有进程句柄的浏览器，再处理 Esc / Ctrl+Shift+Q，其余输入原样放行，不记录按键或文本。离开游戏页或关闭窗口即卸载；派发操作前再次确认同一会话，长按 Esc 不会在取消弹窗后继续退出游戏。崩溃或已关闭的游戏页仍可用 Esc 返回桌面。后台实例继续阻止维护更新。
