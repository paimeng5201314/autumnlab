# 内部应用的交互与外观

适用 AutumnOS 0.5.1、SDK 0.3.0、协议1。制作人：派蒙。保留宿主的原生窗口、iPad式桌面、Dock、后台继续/结束、长按/右键和双栏设置；应用不能替换桌面、伪装系统授权或创建外部EXE窗口。样例CSS为工程原创；化学内容仅抽象元素配对，不包含现实实验步骤。

真实宿主状态来自lifecycle快照及事件。返回桌面属于background，输入和牌局保留；suspended限制能力调用；closing意味着开始释放，不应继续新操作。用户点击“结束”后资源未释放的阶段仍会阻止维护。应用没有“强行关闭主程序”SDK；退出由宿主控制。保存按钮要显示真实成功/失败，TIMEOUT或USER_CANCELLED之后不能武断显示已回滚。

权限操作需要明确点击。先申请文件或内部链接权限，授权完成后再点具体选择/链接动作，不能使用异步等待前的旧手势。让未授权用户继续非敏感功能；不反复弹窗、不诱导授权。输入显示使用textContent，不把资料、存档或小组件文本拼成HTML。不要加载远程头像来偷偷绕过网络权限。

外观从appearance.get和appearance.changed读取，处理light/dark/system、language、scale、reduceMotion。先订阅，再读取初值并防止迟到初值覆盖新事件；重回前台再同步快照。Windows/WebView可能已应用DPI，不要重复放大；样例共享壳尊重系统主题及减少动态，但不声明完整多屏/触屏验收。

键盘Tab/Enter应与按钮一致，提供明显焦点和状态区域。真实检查必须包含WebView上方宿主菜单、权限弹窗、通知与结束面板可见可点，不能用DOM替身证明原生覆盖层正确。现有配对支持方向键，hello模板保留未保存输入用于同实例恢复。参见[桌面扩展](desktop-extension.md)和[排错](troubleshooting.md)。
