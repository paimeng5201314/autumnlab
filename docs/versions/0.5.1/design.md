# 界面与交互 · 0.5.1

AutumnOS 0.5.1 的桌面使用三列网格，已有主题、壁纸、设置页、通知区及运行切换器。界面必须描述实际动作，不能把部分编辑能力写成完整桌面，也不能继续提示“固定布局、无法编辑”。制作人署名为派蒙，产品名为 Lab Chronicles AutumnOS；版本与构建信息取真实产物，不能用设计稿截图充当运行状态。

单击图标、Enter 或 Space 打开应用；已有后台实例时继续同一实例。双击桌面空白处或按 F6 打开“正在运行”，从卡片中继续或确认结束。图标、Dock、小组件和滚动条不是空白区域。Esc、完成按钮或遮罩关闭切换器，不结束应用。结束取消后保留实例与未保存输入，确认后还要重新核对捕获的实例身份。

按住桌面图标拖到另一个图标后松手可改变顺序；长按、右键或 Shift+F10 菜单中的“向前移动／向后移动”提供键盘可达的等价入口。移出网格后松手、Esc、窗口失去激活、切页或调整窗口大小会取消拖动。只有持久化成功后才更新排列；配置读取失败时显示只读状态，不能覆盖坏配置。隐藏再显示的开发者入口保留原排序位置。

| 能力 | 当前边界 |
|---|---|
| 三列图标排序、重启保留、运行切换器 | 已有实现；具体设备与本次构建仍需原生回归 |
| 长列表 | 可滚动；拖动到边缘不自动滚动 |
| 文件夹、多桌面、完整搜索、自定义 Dock、抖动编辑 | 尚未提供完整实现 |
| 控制中心音量、网络 | 尚未接入可调整系统服务 |
| 物理触屏/笔、多显示器、DPI、输入法 | 需专项验证，鼠标自动化不替代 |

UI 更新应保留 AutomationId、可见错误与取消路径，遵守系统减少动态效果设置。验证至少覆盖拖动取消后键盘可用、保存失败不移动、重启排序、只结束选中实例、后台维护阻塞。扩展应用的通知、快捷动作和小组件边界见 [桌面扩展](desktop-extension.md)，完整状态记录见 [协作与证据](collaboration.md)。
