# 使用、恢复与安全排错

适用 AutumnOS 0.5.1、SDK 0.3.0、协议1。制作人：派蒙。解压整个便携ZIP到用户可写目录，保留同级DLL、PRI/XBF、WebView2Runtime和Developer；双击AutumnOS.exe。不以管理员运行、关闭安全保护或移动用户数据作为默认修复。当前机器成功不证明干净Windows10或离线首次启动通过。

再次启动应唤回现有窗口；不同目录旧版可能仍持有全局业务锁。测试前正常退出用户旧窗口，不能按进程名强杀。游戏返回桌面仍运行，保存输入后选择真正结束；显示关闭中时等待资源释放。原入口更新维护期间有等待状态，不要手动进入半替换目录启动Client.exe。

更新缺生产公钥时不能自动安装；离线、限流、无合规Release和验签失败是不同结果。保持生产TLS/签名，不把代理回退当成跳过验证。安全回退发生后保留错误报告及原数据，同一坏版本不会无限重试。若目录资源缺失，先退出程序，再从同一可信完整包恢复程序文件；不要用旧程序覆盖不兼容数据或删除失败日志来强行变绿。

应用错误可先记录BuildId、固定错误code和correlationId、步骤、时间及是否在游客/已登录状态。不要粘贴完整callback、授权码、access/refresh token、Cookie、密文凭据、私钥或用户文件内容。当前开发跟踪仅有限方法名/固定结果码，关闭模式清除；它不是完整支持包脱敏系统的自动验收。导出诊断前阅读实际范围并检查内容，不将整个AutumnOS_Data作为审阅包附件。

需要本地诊断包时，在设置→开发者诊断点击“导出脱敏诊断包”，阅读原生说明后选择文件夹；默认取消，不自动上传，不覆盖已有文件。ZIP只有support.json和events.json：版本/BuildId/源快照、系统版本、更新阶段以及固定白名单事件。每种日志最多读1MiB、保留200条有效事件，忙、超限或无权限的来源明确省略；原日志、路径、账号、凭据、存档、应用内容、截图均不整包导出。现有日志写满1MiB后停止新增，没有自动轮转或删除。SUPPORT_EXPORT_FAILED表示导出未完成，先核对目标权限或维护状态，保留失败文件和原日志；成功后自行打开JSON检查再决定分享。此功能不是用户数据备份，也不是发布或制作人批准记录。

原生应用启动失败时，runtime-events.jsonl保留startup_failed及固定阶段（package/session/resources/profile/environment/controller/settings/navigation）、有限异常分类、数值HRESULT和profile路径字符数，不写异常消息、路径或账号。profile_prepared、environment_created和controller_created可区分实际失败阶段。WebView2在profile根下创建额外目录；宿主现在使用Runtime/wv下的单个完整SHA-256身份目录，避免旧账号hash/应用binding hash两层路径在深中文便携目录耗尽原生路径长度。不会修改Windows长路径策略。极端深目录仍以实际启动结果为准，不能保证任意长度目录均可运行。

HOST_UNAVAILABLE应通过内部包运行；PERMISSION_NOT_DECLARED修清单；DENIED/REVOKED由用户管理权限，不循环申请；USER_GESTURE_REQUIRED需要新的真实点击；SESSION_EXPIRED需重新打开实例；TIMEOUT/USER_CANCELLED后先读回确认，写入可能完成。网络能力不支持要遵守边界。损坏存档先保留原件，使用宿主验证过的备份恢复，不从客户端传路径。

整目录备份应正常关闭所有实例后复制AutumnOS_Data，注明版本与账号上下文；账号密文受当前Windows用户保护，不能保证跨设备直接复用。恢复时先另存当前数据，按兼容版本操作；实际外部文件选择器/备份功能的正反例见[数据](data.md)。未运行情况记录not_run，不为了消除提示覆盖用户文件。

开发预览显示“测试模拟”时先用CLI debug status核对当前sessionId及simulation，再按[第一个应用](first-app.md)执行restore-permissions、online或原生确认reset-simulation。reset会重建预览并返回新ID，先保存未提交输入；默认取消不会切换。DEVELOPER_PREVIEW_SESSION_EXPIRED表示旧ID已不能控制新实例，DEVELOPER_MODE_DISABLED需用户明确开启模式，DEVELOPER_BUSY需等待当前操作，不重试循环。关闭开发模式释放预览/管道并清除内存模拟状态；独立测试存档保留，真实账号及正常应用数据不由此删除。
