# AutumnOS 版本清单

制作人：派蒙。自 1.0.1 起，正式版和测试版共用三段十进制产品号。每段使用整数，零以外的数字不带前导零。产品版本按主版本、次版本、修订版本的数字顺序比较。

| 字段 | 稳定版示例 | 测试版示例 |
|---|---|---|
| 产品版本、SDK、自带官方应用版本 | `1.0.1` | `1.0.1` |
| 关于页、EXE 产品版本和 GitHub 发行标题 | `v1.0.1` | `v1.0.1` |
| 渠道、Git 标签、签名清单的 releaseTag | `v1.0.1` | `metav1.0.1` |
| GitHub 发行属性 | Latest | Pre-release |
| 2026 年 11 月 21 日构建的 ID | `v1.0.1-20261121` | `v1.0.1-20261121` |
| Windows 文件版本、程序集版本、应用清单身份 | `1.0.1.0` | `1.0.1.0` |

### 构建与签名

`build/Brand.props` 保存当期产品号和签名计数。构建入口从产品号生成显示版本、四段 Windows 版本及当日构建 ID。日期取构建机器的本地日历。一次构建生成一个源码 SHA-256 快照。相同版本在同一天共用一个构建 ID，已有证据目录禁止覆盖。新的可分发二进制需要可区分的构建身份，尤其是预览转正式时。

1.0.1 的首个签名修订为 `sequence=1`。新清单分别签署产品内修订和跨版本安全计数 `securitySequence`。后者从已发布的 6 接续到 7，每次正式签发不同清单时递增。产品内后续修订也须递增。签名本身由现有生产密钥生成。实际摘要、签名和发布资产 ID 取自对应产物。

### 分发与兼容

GitHub 标签与签名清单的渠道、发行标签必须相等。可以离线查看请求参数：

```powershell
./scripts/Get-GitHubReleaseMetadata.ps1 -Version 1.0.1 -Channel v1.0.1
./scripts/Get-GitHubReleaseMetadata.ps1 -Version 1.0.1 -Channel metav1.0.1
```

1.0.0 客户端只接受上一代更新清单。首次迁移到 1.0.1 时，正常退出游戏和启动器，备份原来的 `AutumnOS_Data`，在原目录换用新版完整 `AutumnOS.exe`。历史发布与回退证据按原标签保存。

开发者模板从当前官方版本起步。独立安装的第三方应用按作者自己的版本比较。厂商库版本、支持的 Windows 版本、IPC 协议和存档格式用于实际兼容判断，分别由相应维护者管理。快照、哈希、提交和发行记录 ID 用于校验身份，不参与产品版本排序。
