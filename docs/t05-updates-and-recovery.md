# T05 系统更新与恢复

Lab Chronicles AutumnOS · 制作人：派蒙。本文是当前本地实现操作说明；完整验收和真实证据以 `AUTUMNOS_PROGRESS.md` 为准。

在桌面打开设置，选择左栏「系统更新」。显示实际程序集版本和构建、渠道、上次检查、候选说明、下载字节、验证和等待原因。新引入的独立配置 `AutumnOS_Data/Config/system-update.json` 默认自动更新开启、预览关闭；不迁移或重置外观、桌面和账号配置。关闭预览仅选择 plus；打开预览仅选择 meta。游戏商店的各应用预览设置不受影响。当前版本高于正式渠道时等待后续新版，不能自动降级。

手动「检查更新」读取固定 `paimeng5201314/autumnlab` 的 Release 列表。生产公钥缺失会明确报告自动安装未配置，即使网络正常也不能宣布签名更新可用。检查不需要账号或 GitHub PAT。更新说明是纯文本。自动检查在初始化后异步执行，随后最多每六小时检查；手动操作允许立即重试。网络代理与限速沿用 GitHub 加速设置，身份与游戏流量不经过该服务。

发现合规候选后可「下载并验证」；自动更新开启时自动准备。验证完成只代表已准备。前台、后台、挂起、启动中、正在结束或资源尚未释放的游戏都会等待；继续玩游戏和保存仍可用。安装、存档/配置、恢复/迁移及身份关键写入受统一协调。系统应用仍在编辑、确认对话框或账号操作时也延后；返回桌面或停留更新页后才进入重启提示。没有保存能力的应用不会被更新强行结束。

空闲后显示十五秒的重启提示，可以「稍后重启」。下载/等待可取消；进入交接边界会禁用业务输入和取消按钮。主程序先取得排他维护资格，再重新检查渠道、候选、游戏和关键写入，独立更新器重新验签与验证负载后才授权旧进程正常退出。

`AutumnOS.exe` 是稳定自包含引导，`AutumnOS.Client.exe` 是 WinUI 业务程序。外部快捷方式继续指向原根的 `AutumnOS.exe`。数据始终保留在同根 `AutumnOS_Data`，账号 DPAPI 记录不复制到其他位置、不进入发行 ZIP。普通升级只接受可回退的 schema 1；需要不可逆数据迁移的清单明确拒绝，不让旧程序读取不兼容的新数据。

事务记录和旧程序备份在同根 `.autumnos-update`，不是用户数据目录。新版须完成资源、配置、应用注册及主要存储初始化，并完成受限管道健康确认。窗口出现和进程存活不算成功。失败后保留报告和旧版本备份，恢复原程序，记录坏构建以阻止自动循环。再次双击稳定入口会等待维护或根据持久日志进入恢复；不要删除该目录中的恢复证据。

错误处理：`UPDATE_PRODUCTION_TRUST_NOT_CONFIGURED` 等待接入可信生产公钥；`UPDATE_METADATA_EXPIRED`/时钟异常需核对本机时间并重新获取可信元数据；签名、来源、摘要或文件表失败时保留现版，不能关闭验证；空间不足先释放与用户数据无关的空间；文件占用请正常关闭其他使用同安装根的客户端。恢复失败时保留整个安装根、事务日志和备份，停止重试，不手工清空存档。

替换前因文件占用停止时，原版本从稳定入口重新打开，并按持久 `aborted` 记录暂停自动重启。后台检查和下载仍可继续，关闭占用后由用户明确选择「重启更新」重试。该临时占用不等于坏版本，但不能让客户端在占用持续期间自动退出、重开循环。

普通开发包、仅本地更新演练包必须分别放置。演练包的测试公钥和固定本地 feed 编译进测试构建，不能由普通设置或启动参数启用。生产包没有测试根。历史 T04 包不含 T05 协议，不能拿它作为可更新的 A；应使用包含完整更新协议的独立 A/B 构建。

T03 真实第二账号、长期刷新/过期等未完成验证继续暂缓。当前同根升级不改变凭据保护规则；测试哨兵和合成 OIDC fixture 不等于真实账号升级验收。Windows 10、干净机器和物理输入矩阵未实测的部分保持 `not_run`。
