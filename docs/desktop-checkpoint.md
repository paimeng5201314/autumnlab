## 页面与真实状态

MainWindow 是 WinUI 原生窗口，DesktopUi 负责原创矢量壁纸、图标和输入。首启 Hello → Brand → Initializing → Completed 使用已有 FirstRunStateStore，逐步提交；初始化前关闭会从最近检查点恢复。旧版 Completed 记录直接进入桌面。页面覆盖整个工作区，应用打开后占用该工作区，诊断页不再是首页。操作系统关闭动画时页面不做淡入。

桌面从 PackageInstaller.Install 的已提交/已验证结果生成自带样例入口，名称来自实际清单；不存在有效安装就不生成游戏图标并报告安全错误码。新版样例 0.2.0 与旧 0.1.0 并存；原 appId 和游客存档位置保持一致。启动前运行器再次验证，避免桌面出现图标后资源遭更改仍被执行。当前范围仍只开放随附样例，不宣称普通第三方沙箱已经验收。

返回桌面调用真实 Background，保持 WebView2/RuntimeSession；桌面与 Dock 图标显示“运行中”状态，不再显示居中提示卡。未运行时单击打开；后台运行时单击保持后台、双击在图标旁打开原生操作面板，提供“继续游戏”和“结束游戏”。继续复用同一实例；结束需确认并 Dispose 当前 WebView/RuntimeSession，清除运行标记，再次单击才创建新实例，存档保持。操作面板与菜单捕获宿主引用及实例 ID，执行前再次核对，确认弹窗返回后也核对，防止旧操作影响新会话。维护判断还不是 T05 跨进程锁。

设置作为双栏系统应用打开：左栏分组图标导航保持可见，默认选中“外观”，切换“外观 / 桌面与 Dock / 通知与控制中心 / 开发者诊断 / 关于”只改变右栏内容及真实选中态。导航选择是本次窗口的界面状态；持久化设置仍只有已实现的主题和壁纸。light/dark/system、warm/mist/night 使用 DesktopPreferencesStore，只有写入成功才应用新外观，重启后恢复。路径、容量、原子替换、schema 和错误合同见 desktop-preferences.md。桌面与 Dock 页读取真实安装清单和运行状态；通知与控制中心如实显示未接入状态，不放置不可保存的开关或占位按钮。原初始化、目录、公开 Logto 检查仅在左栏高级组的“开发者诊断”。关于显示集中品牌、制作人派蒙、真实程序集版本与构建 ID。没有商店、下载、账号成功的模拟卡片。

## 输入与视觉

图标左键按住 600 ms 打开原生菜单；移动任一方向超过 8 DIP 取消本次计时。长按不会顺带启动应用，右键、Shift+F10 等价；运行中菜单同样提供“继续游戏 / 结束游戏”。后台图标 Enter/Space 打开操作面板，未运行时按原生按钮规则启动。菜单使用 WinUI Flyout 的 Escape 和点击外部关闭。此检查点没有声称拖动排序已完成。

内置壁纸由本地 XAML 曲线、渐变和形状组成，没有复制 Apple 素材。状态栏为本机时钟、品牌和可操作的外观入口；Dock 仅显示已实现入口。截图只取自实际程序窗口；最终视觉质量由派蒙审阅。

执行 Build.ps1、Test.ps1、Test-DesktopInteractionSmoke.ps1 和 Package.ps1。旧 Test-DesktopSmoke.ps1 与历史产物/报告保留，针对旧交互；新脚本验证本次双栏和后台面板。Package.ps1 必须从实际交付目录复制到中文空格路径执行新桌面测试，通过后才打 ZIP；保留此前 WinUI 资源补齐和字节哈希校验。源快照包含新源码、SDK、文档、测试及脚本；build ID 嵌入程序集。

新桌面测试覆盖全窗口首启、浅深桌面、五类左栏导航、主题/壁纸落盘与重启保持、安装入口、真实鼠标单击/双击、长按/右键菜单、内部游戏保存与返回桌面/同实例继续、真实结束及新实例重新读档、开发者诊断。截图均来自实际 Windows 窗口。实际执行结果以 artifacts/builds 对应报告为准；在执行前属于 not_run。本次没有进入 T03，也没有变更 Runtime、Packages、Storage 和 SDK 的接口或测试。

自动化使用原生 UI Automation 与合成鼠标/键盘输入；后台单击前采日志基线，继续后必须出现同实例的新 Foreground 事件。测试仅操作其自行启动的隔离窗口，可临时置顶并通过自有标题栏正常激活；每次输入核对当前指针、控件边界与窗口归属，截图前后检查遮挡，窗口失去前台时拒绝发输入。此条件写入报告，不修改系统前台策略、不关闭用户已有程序，也不冒充物理触控或人工审阅。交付 EXE 另作普通窗口启动检查。
