# 隔离研究与历史证据

制作人：派蒙。

本目录归档项目自己的隔离探针源码、脚本和审阅结论。它们是研究材料，不是第三方应用的放行清单，也不证明完整隔离已通过。失败、未执行和后续清理后缺失的历史证据仍按原状态记录。

`isolation-20261018/drafts/` 对应原工作区 `artifacts/isolation-20261018/drafts/`；部分脚本与项目引用使用原相对布局，复现前应按清单中的 `source_path` 恢复该布局，并先阅读对应审阅说明。归档没有执行这些探针，没有重放历史UAC授权，也没有改变窗口站、防火墙或系统安全策略。

公开副本仅对结论/报告中的本机路径与用户SID作脱敏，代码字节保持原样。公开源码清单记录原字节摘要和公开摘要。网页抓取、Chromium源码摘录、系统进程/防火墙枚举原始数据、缓存、二进制、私钥和用户数据不在本目录。

当前正式运行策略仍拒绝没有可靠剪贴板边界的外部应用；ChemLeap普通模式没有因此获准启动。Windows发布者签名和AutumnOS自己的更新清单签名是独立验证层。
